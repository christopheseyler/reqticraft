# Preuves d'interopérabilité en boîte noire

Ce dossier répond aux questions ouvertes de `../interop-formats.md` §10 (Q1 à Q8).

Chaque expérience a son sous-dossier `QN-sujet/` :

- `NOTE.md` : date, version de Reqtify, manipulation faite dans l'interface, conclusion ;
- `input/` : nos documents de test (jamais un fichier livré par Dassault Systèmes) ;
- `output/` : les fichiers enregistrés par Reqtify à partir de ces documents.

Une fois la conclusion reportée dans `interop-formats.md` avec l'étiquette **[BB]**, l'hypothèse
**[INF]** correspondante est retirée.
